# LLM 调用架构与报告内容设计说明

面向场景：香港投行研究所新人分析师，早上港深通勤时、早会前快速把握形势与变化。

## 1. LLM 调用：层层拆解（分层 DAG），不是一次长对话

结论：**层层拆解**。一次长对话会稀释上下文、无法并行、无中间检查点；分层拆解把报告拆成有依赖关系的聚焦任务。

```
                 ┌─────────────┬──────────────────┬───────────────┐
                 │ news_sel    │ macro_interpret  │ company_comm  │ theme_deep_dive │   (Phase 1 · 并行)
                 └──────┬──────┴────────┬─────────┴───────┬───────┴────────────────┘
                        │               │                 │
                        ▼               │                 │
                 overnight_review ◄─────┘                 │          (Phase 2 · 依赖 news_selection)
                        │                                 │
                        ▼                                 │
                    hk_review ◄───────────────────────────┘          (Phase 3 · 依赖 overnight + 本地资金流)
                        │
                        ▼
                 final_framing                                          (Phase 4 · 汇总全部上游)
```

- **Phase 1（并行）**：`news_selection`（选新闻）、`macro_interpretation`（宏观解读）、`company_commentary`（公司点评）、`theme_deep_dive`（主题深挖）——互不依赖，用 `ThreadPoolExecutor` 并行，满足 07:30 交付 SLA。
- **Phase 2**：`overnight_review`（隔夜复盘）依赖已选新闻。
- **Phase 3**：`hk_review`（港股复盘）依赖隔夜定调 + 本地资金流。
- **Phase 4**：`final_framing`（最终定调）汇总**全部上游输出**，产出早会的一句话结论。

为什么这样优于单次长对话：
1. **上下文聚焦**：每个任务只见自己需要的事实，不被无关字段稀释（长对话会把 300 个字段塞进一个 prompt）。
2. **可并行**：叶子任务并发，总延迟≈最长任务而非任务之和。
3. **可缓存/可降级**：每个任务独立缓存（`llm_cache`），任一失败不拖垮整份报告（确定性兜底文案接管）。
4. **中间结果可审计**：`fact_checker` 能对每段 LLM 文本做数值核验，单次长对话无法定位是哪段出错。
5. **可路由**：小任务用 fast_model、深任务用 deep_model，成本与质量分层。

## 2. 报告内容长短与编排（通勤版）

三层阅读路径（早会前 5 分钟 → 有时间再深读）：

| 层 | 定位 | 时长 | 内容 |
|---|---|---|---|
| **WeCom 摘要** | 手机 5 分钟扫描 | ~1 屏（3800 字节预算） | 一句话结论 + 决策框架 + 无效化条件 |
| **Layer 1** | 扫描层 | 5 min | 昨日 call、跨资产仪表盘、港股快速检查、决策板、清单 |
| **Layer 2** | 深读层 | 20-30 min | 隔夜/港股/AI-TMT/资金流/宏观/公司/早会问题/核心标的 |
| **Layer 3** | 决策深化 | 10-15 min | 主题深挖、今日日历、图表 |
| 附录 | 溯源 | 可选 | 质量、绩效、来源链接 |

编排原则（本次审计已落地）：
- **先结论后证据**：Executive Summary 用 4 个固定问题回答（昨日 call / 隔夜变化 / AI-TMT 含义 / 今日关注），一眼扫完。
- **不重复**：同一事实只说一次（已修：ETF 代理表重复、mode-lens 重复、quality 分重复）。
- **信息质量优先**：缺数据就说"不可用/无方向"，绝不编造"走平"或把成交额当净买入。
- **字数预算**：目标 4200-6000 词、硬上限 7000（`runtime_audit` 事后审计，超限告警）；WeCom 摘要 3800 字节硬约束。
- **全球视角三市场日期**：报告头明确 `US/global`、`HK`、`A-share` 三个数据日期，各自按对应市场节假日回退。
